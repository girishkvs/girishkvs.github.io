Featured project

MCP Pacemaker

Agent infrastructure · Open source

A managed local runtime for the tools behind AI agents. MCP Pacemaker separates tool-server lifecycles from the editors and CLIs that use them, bringing supervision, authentication, configuration, and diagnostics into one place.

I built it to make an agent workspace easier to operate across sessions and hosts, instead of treating every tool server as a disposable editor subprocess.

  • Runs MCP servers independently, with process supervision and auto-start across Windows, macOS, and Linux.
  • Connects editors and agent CLIs through standard MCP transports, with configurable isolation, pre-warming, and shared-process modes.
  • Centralizes pluggable authentication, expiry-aware credential refresh, and scheduled server recycling.
  • Combines configuration planning and backups with live web and terminal dashboards, health checks, durable logs, and process-launch metrics.
