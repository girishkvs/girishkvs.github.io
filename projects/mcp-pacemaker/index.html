MCP Pacemaker

Keep your MCP servers outside the editor.

Editors and one-shot CLIs often own the stdio MCP servers they start. When the host exits, those subprocesses stop too. MCP Pacemaker moves process supervision into a local bridge.

I built it to keep server setup and diagnostics in one place, rather than repeat them for every editor and agent CLI.

Source on GitHub Package on npm

  • Manage MCP server processes and OS auto-start from one place on Windows, macOS, and Linux.
  • Isolate sessions by default, with opt-in pre-warming and compatible process sharing.
  • Inspect connected clients, server health, and durable logs through local web and terminal dashboards, without opening an editor.
